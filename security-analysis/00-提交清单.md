## 本次验证摘要

两个问题均使用一次性测试用户名和虚假密码标记，在隔离的 NebulaGraph 测试服务中完成动态验证。客户端由上游 `master` 提交 `8ea370a0125cdb8f76a8e324aaaf1d2cb3ed051b` 编译。

- 成功执行的 `CREATE USER ... PASSWORD ...` 在正常退出交互模式后仍被明文保存在历史文件中。
- 服务端拒绝的含密码语句同样被保存，证明记录发生在获知执行结果之前。
- 在验证进程的 umask 下，历史文件最终权限为 `0664`，与源码使用 `0666` 创建且仅受 umask 修正相符。
- `-e/--eval` 和普通 nGQL 文件的 `-f/--file` 模式均在 stdout 中出现了测试密码标记。
- 验证后已删除所有测试用户、隔离历史和临时 nGQL 文件。
